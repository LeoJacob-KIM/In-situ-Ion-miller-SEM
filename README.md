# In-situ Ion Miller + SEM

수직 SEM 측면에 ICP 이온 밀러를 직각으로 결합한 In-situ 단면 분석 시스템 자료입니다.
이온 밀러로 시료 단면을 가공한 뒤, 시료를 꺼내지 않고 같은 진공 안에서 SEM으로 바로 관찰합니다.
